Method 1: Instant In-App Data Purge

Eradicate all local storage and database entries in seconds.

1. Open the Application and click "SETTINGS" in the top bar.

2. Clear all input tokens or click "Reset Connection".

3. Open browser DevTools -> Application -> Storage -> Click "Clear site data" to wipe all cached posts and credentials.

4. If using Supabase, drop your database tables or delete the project.

02

Method 2: Revoking Social Media Authorizations

Sever API tokens directly in your platform account settings.

• Meta / Instagram / Facebook: Settings & Privacy -> Settings -> Apps and Websites -> Remove Swiss Content Engine.

• X (Twitter): Settings and privacy -> Security and account access -> Apps and sessions -> Connected apps -> Revoke access.

• TikTok: Settings and Privacy -> Security & Permissions -> Manage App Permissions -> Remove Access.

• Google: myaccount.google.com -> Security -> Third-party apps -> Remove Access.
